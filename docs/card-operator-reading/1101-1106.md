| `limit` | `UsageLimit` | count1/reset each_turn/consume on_accept/optional True |
| `dur` | `Duration` | me在场且位于战场 |

API调用：

```python
ops.replace_event(events, rewrite, duration=dur, optional=True, limit=limit)
```
