## 0101 Blind Fury

- 判定：**covered**。
- 本轮独立复读：依Origins勘误每个对手先展示顶牌，再选一放逐后由本方忽略基础费打出，余牌各回拥有者牌底；跨玩家展示按程序批次，不能提前查看后续对象。
- 入口、条件和角色：迅捷法术；按勘误各对手顶牌展示，选1先放逐再由p免费打，余回收
- 参数绑定：opponents:list[Player]=所有对手;tops:dict[Player,Selection[Card]]=各对手顶至多1;c:Card=p从实际展示牌选的一张;dest:Location/Zone=该牌合法目的地;rest:Selection[Card]=未被选的展示牌
- 固有关键词核对：Action
- 本体属性：类型=['spell']；领域=['fury']；Energy/Power/Might=4/2/None；标签=[]。
- [历史原文与印刷属性](../card-operator-reading/0101-0200.md#card-0101)。


**入口／片段：迅捷法术；按勘误各对手顶牌展示，选1先放逐再由p免费打，余回收**

```python
with flow.Batch(policy=PLAYER_PROCEDURE):
    for actor in opponents:
        with action_frame('reveal', {'positional': (tops[actor],), 'keywords': {'actor': actor}}) as f1:
            p.information_access(f1.objects, f1.viewers, mode='REVEAL', duration=f1.duration)
with action_frame('banish', {'positional': ([c],), 'keywords': {}}) as f2:
    p.zone_change(f2.objects, f2.origin, f2.owner_banishment)
with action_frame('play', {'positional': (c, player), 'keywords': {'origin': c.owner.banishment, 'destination': dest, 'cost_policy': IGNORE_BASE_COST}}) as f3:
    with phase('start'):
        if f3.new_template:
            born = p.instantiate(f3.template, f3.count, owner=f3.owner, controller=f3.controller, initial=f3.entry)
            f3.bind_newborn(born.value)
        p.zone_change(f3.objects, f3.origin, f3.chain_zone)
    with phase('enter_permanent'):
        p.zone_change(f3.objects, f3.chain_zone, f3.board, entry=f3.entry, entry_location=f3.entry_locations)
    with phase('spell_leave_chain'):
        p.zone_change(f3.objects, f3.chain_zone, f3.leave_destination)
with action_frame('recycle', {'positional': (rest,), 'keywords': {}}) as f4:
    with flow.Batch(policy=SIMULTANEOUS):
        for group in f4.recycle_groups:
            if group.same_zone:
                p.order_change(group.objects, group.deck, position='bottom', order=group.order)
            else:
                p.zone_change(group.objects, group.origin, group.deck, position='bottom', order=group.order)
```
