## 0001 Abandon

- 判定：**covered**。
- 本轮独立复读：反应入口与无效化后回拥有者手牌保持同一法术；先取消链项再走离链区域替代，随后洞察独立信息授权及可选回收，不把放逐流转覆盖遗漏。
- 入口、条件和角色：法术结算；固有反应
- 参数绑定：spell:ChainItem=所选法术
- 固有关键词核对：Reaction；Predict:body
- 本体属性：类型=['spell']；领域=['chaos']；Energy/Power/Might=2/None/None；标签=[]。
- [历史原文与印刷属性](../card-operator-reading/0001-0100.md#card-0001)。


**入口／片段：法术结算；固有反应**

```python
with action_frame('counter', {'positional': (spell,), 'keywords': {'destination': spell.owner.hand}}) as f1:
    p.chain_cancel(f1.item)
    if f1.has_card:
        p.zone_change([f1.card], f1.chain_zone, f1.leave_destination)
with action_frame('predict', {'positional': (player,), 'keywords': {}}) as f2:
    p.information_access(f2.looked, [f2.player], mode='LOOK', duration=UNTIL_EFFECT_END)
    f2.bind_recycle_choice(flow.Choose(player=f2.player, kind='object', candidates=f2.looked, minimum=0, maximum=f2.count, targeting=False, stage='resolution', shortage='as_many_as_possible'))
    if f2.to_recycle:
        with action_frame('recycle', {'positional': (f2.to_recycle,), 'keywords': {}}) as recycled:
            p.order_change(f2.to_recycle, f2.main_deck, position='bottom', order=f2.recycle_order)
    if f2.kept_on_top:
        p.order_change(f2.kept_on_top, f2.main_deck, position='top', order=f2.chosen_top_order)
```
